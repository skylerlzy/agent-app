# 迭代三成员二：跨对话知识共享与 RAG 知识增强

## 内置知识库

- **来源**：[English Wikivoyage](https://en.wikivoyage.org/wiki/Main_Page)
- **范围**：中国 9 个一线城市 + 44 个二线城市（共 55 份文档，含 China 总览）
- **数据文件**：`lib/agent/knowledge/data/builtin-wikivoyage.json`
- **重新生成**：
  - 有网络：`npx tsx scripts/generate-builtin-wikivoyage.ts`（拉取 Wikivoyage 全文）
  - 离线种子：`npx tsx scripts/generate-builtin-wikivoyage-offline.ts`

用户**不可上传**或批量导入；知识库仅内置只读。

## RAG 检索

- 混合检索：关键词 + DashScope 向量（RRF 融合）
- 内置攻略向量在 action 内缓存（`builtinEmbeddingCache`）
- 设置页检索预览：Top-2 全文

## 验收

1. `/settings/knowledge` 显示 55 份内置文档
2. 检索预览「南京晚上适合去哪」→ Top-2 块
3. 对话同句 → Trace **知识检索**（LLM 判定，非 skipped）
4. 回答含 `[来源: …]` 或参考来源区块
