# 在另一台电脑上运行 agent-app（尽量少配置）

## 先说清边界

| 能否做到 | 说明 |
|----------|------|
| **完全不装任何软件** | 在**自己电脑**本地跑 Next + Convex + Clerk + 大模型，**做不到**。至少要有一个「运行时」（浏览器只够访问**别人部署好的网站**）。 |
| **对方只装一样东西** | 可以：只装 **Docker Desktop**，用本仓库提供的 **`docker compose` + 一键脚本**，不在对方机器上单独装 Node。 |
| **对方完全不用配环境变量** | 只有在你把 **`.env.local` 一并提供给对方**（U 盘 / 加密网盘 / 私发）且对方**只负责不泄露**的前提下成立。密钥**不要**提交到 Git。 |

课程/答辩推荐两种「对方省事」的方式：

1. **Docker 一键起本地站**（本文档）——适合「带笔记本现场演示」或助教同一内网验收。  
2. **你方部署到线上**（如 Vercel + Convex 生产环境）——对方**只点链接**，本机零安装；代价是你维护部署与密钥。

---

## 方案 A：Docker 一键启动（推荐：另一台电脑只装 Docker）

### 对方电脑需要

1. 安装并启动 **[Docker Desktop](https://www.docker.com/products/docker-desktop/)**（Windows / Mac；Linux 装 Docker Engine 即可）。
2. 获得你的项目目录（U 盘 / Git 克隆 / 压缩包解压均可）。
3. 获得一份已填好的 **`.env.local`**（由你从本机复制；内容参考仓库根目录 **`.env.sample`**）。

### 操作步骤

1. 把 **`agent-app` 整个文件夹** 拷到对方电脑任意路径。  
2. 将 **`.env.local`** 放在 **`agent-app` 根目录**（与 `package.json` 同级）。  
3. **Windows**：双击 **`一键启动.bat`**。  
   **Mac / Linux**：在终端进入该目录后执行：
   ```bash
   chmod +x 一键启动.sh
   ./一键启动.sh
   ```
   或直接：
   ```bash
   docker compose up
   ```
4. 首次启动会在容器里执行 **`npm ci`**，可能要 **1～3 分钟**。完成后用浏览器打开：  
   **http://localhost:3000**

### 说明

- `docker-compose.yml` 会把当前目录挂载进容器，在容器内安装依赖并执行 **`npm run dev`**，与你在本机开发效果一致。  
- **`node_modules`** 使用 Docker 命名卷缓存，第二次起会快很多。  
- 若依赖有变更，可在项目目录执行一次：  
  `docker compose run --rm web sh -c "rm -rf node_modules && npm ci"`  
  或删掉卷：`docker compose down -v` 后重新 `up`（会重新全量安装）。

### 常见问题

- **没有 `.env.local`**：脚本会提示。必须从 `.env.sample` 复制并填写 **Clerk、Convex、DashScope、高德、和风** 等（与 Convex Dashboard 一致）。  
- **Convex**：对方电脑**不必**安装 Convex CLI；只要 `.env.local` 里 **`NEXT_PUBLIC_CONVEX_URL`** 等指向**你已部署好的** Convex 后端即可。  
- **防火墙**：确保本机 **3000** 端口未被占用且防火墙放行（仅本机访问一般无需额外设置）。

## 方案 B：零安装访问（部署到线上）

把应用部署到你控制的域名（例如 **Vercel** 托管 Next.js，**Convex** 托管后端），把环境变量配在平台控制台。对方：

1. 不需要安装 Docker / Node。  
2. 浏览器打开你给的 **URL** 即可。

适合「评委 / 同学只体验界面」的场景。部署步骤见各平台官方文档与仓库 `README.md`（若有 CI/CD 可一并写上）。

---

## 与「完全零配置」的差别（答辩时可一句话说明）

本地运行真实 Agent 依赖 **Node 或 Docker** 之一，且 **API 密钥不能公开写进仓库**；因此「一键」在工程上指：**一键命令 + 单一运行时 + 一份随项目分发的私钥文件**，而不是「对方裸机双击 EXE 且无任何凭据」——后者仅适用于纯静态页或全托管 SaaS。
